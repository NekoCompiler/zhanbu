# 玄机排盘 · 梅花易数占事应期

一个**纯静态单页应用**：输入姓名、生日、性别、出生地、所在地与所求之事，按起卦那一刻的系统时间排盘，输出「事成概率」与「天定应期」（公历 / 农历 / 干支四柱 / 黄道吉神时辰）。

零后端、零依赖、零构建，浏览器直接访问。

## 部署到 Vercel（三选一）

**方式 A · 导入 Git 仓库（最简单）**
1. 把本目录 5 个文件推到 GitHub / GitLab / Bitbucket 仓库根目录。
2. 打开 [vercel.com/new](https://vercel.com/new)，Import 该仓库。
3. Framework Preset 选 **Other**（或保持默认自动识别为 Static），其余全部留空，点 **Deploy**。
   不需要 Build Command，不需要 Output Directory，不需要环境变量。
4. 部署完成得到 `https://xxx.vercel.app`，手机浏览器直接打开即可。

**方式 B · Vercel CLI**
```bash
npm i -g vercel
cd meihua-vercel
vercel --prod
```

**方式 C · 拖拽**
在 Vercel 控制台选择「Deploy from a local folder / Drag & Drop」，把这个文件夹整体拖进去即可（zip 需先解压）。

本地预览：任意静态服务器都行，例如 `python3 -m http.server 8080`，然后访问 `http://localhost:8080`。

## 输入项

- **姓名**：输入框，取字符码点总和入 81 数理，定字气五行。
- **生日**：年 / 月 / 日三个选择框，日数随年月自动校正，周岁自动算出。
- **性别**：选择框，定本命阴阳（其他项依生年天干定）。
- **出生地 / 所在地**：省 → 市两级联动选择，覆盖 34 个省级行政区及全部地级市 / 州 / 盟 / 地区与直辖市辖区。
- **所求之事**：输入框，做语义摄气与事由爻动。
- **起卦时刻**：取浏览器系统实时时间，页面顶部走秒显示，点击「起卦」瞬间锁定。

## 推演链路

1. **合气起卦**：以年支数 + 月 + 日 + 时支数为「时间之经」，再叠入姓名字气数（81 数理）、事由摄气数（语义哈希）与命主日柱气数，分别取 8 得上下卦、取 6 定动爻（先天八卦数 乾一兑二离三震四巽五坎六艮七坤八）。故同一时刻，人与事不同则卦不同。
2. **本卦 / 变卦 / 互卦**：六爻自下而上排布，动爻阴阳翻转得变卦，二三四爻为下互、三四五爻为上互，查六十四卦名表。
3. **体用生克**：动爻所在之卦为用、静卦为体，按五行生克判「用生体 / 比和 / 体克用 / 体生用 / 用克体」；变卦再判一次，权重减半。
4. **干支四柱**：公历转干支（立春 / 交节 / 甲子日锚点 / 日干起时干），得年、月、日、时四柱与命主生辰三柱。
5. **洛书九宫地气**：以中原为中宫，按经纬度方位归坎一、坤二、震三、巽四、中五、乾六、兑七、艮八、离九；出生地为来龙祖气，所在地为坐向磁场，判生成合气与五行生克。
6. **其余加权**：姓名字气数理、动爻得位、月令旺相、大运流年、本命阴阳、事由语义爻动。
7. **概率**：气数基准 50，逐项增减后经 logistic 收敛映射至 3%–97%，保留一位小数；逐项增减在「推演明细」中全部列出。
8. **应期**：以上下卦数、动爻、九宫、流年、事由哈希合成日数，再对齐到用神五行当令之干支日（天干或地支任一属用神即可），取该日四柱、中文农历干支月日，并以黄道十二神（青龙 / 明堂 / 金匮 / 天德 / 玉堂 / 司命）择与用神时辰最近者定吉时。

同一输入在**同一时刻**起卦结果完全确定；时刻一变，卦气即转。地区经纬度以省级中心加市内确定性微扰近似，用于九宫归位。

> 本项目为传统术数模型的文化演示与娱乐推演，不构成任何现实决策依据。
